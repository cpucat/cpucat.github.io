Opcode List

Bin Hex Mnemonic Description
0000 0 NOP Does Nothing
0001 1 NAND A = A NAND DATA
0010 2 AND A = A AND DATA
0011 3 XOR A = A XOR DATA
0100 4 OR A = A OR DATA
0101 5 TR A = DATA
0110 6 SKIP A=D Skips next instruction if A = DATA
0111 7 ADD A = A + DATA
1000 8 SUB A = A - DATA
1001 9 NOT A = !A
1010 A STO A, $D Loads A into the address pointed to by DATA
1100 B LD $D, A Loads the value in $DATA into the accumulator
1100 C SKIP A != D Skips next cycle if A != DATA
1101 D LD A, PC Loads A into the Program Counter (Not required for implementation)
1110 E ROT A Rotates the bits in A to the right (LSB -> MSB)
1111 F HALT Stops any more instructions from being executed

The LogiSim version of this computer is available for download here.


The instruction with opcode 1101 (LD A, PC) is not required for implementation, as this processor was designed to be able to be used with a paper tape reader for simpler operation via the SKIP instructions, which also allows for longer programs to be created.

This processor's opcode list was inspired by the Intel 4004 and UE-1.

The odd data length (5 bits) was chosen for the ability to display baudot code.
