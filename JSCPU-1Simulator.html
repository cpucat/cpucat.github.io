Opcode List

Bin Hex Mnemonic Description
0000 0 NOP Does Nothing
0001 1 NAND A = A NAND DATA
0010 2 AND A = A AND DATA
0011 3 XOR A = A XOR DATA
0100 4 OR A = A OR DATA
0101 5 TR A = DATA
0110 6 SKIP A=D Skips next instruction if A = DATA
0111 7 ADD A = A + DATA
1000 8 SUB A = A - DATA
1001 9 NOT A = !A
1010 A STO A, $D Loads A into the address pointed to by DATA (Currently not in Simulator)
1011 B LD $D, A Loads the value in the address pointed to by DATA into A (Currently not in Simulator)
1100 C SKIP A!=D Skips next instruction if A != DATA
1101 D LD A, PC Loads A into the Program Counter (Currently not in Simulator)
1110 E ROT A Rotates the bits in A to the right (LSB -> MSB)
1111 F HALT Stops any more instructions from being executed
